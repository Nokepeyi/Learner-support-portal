## Screens
| Screen | Purpose | Key elements |
|---|---|---|
| Login / Register | Access the portal | Email, password, name (register), Log in and Register buttons, error message area |
| Dashboard | See progress | Total, completed, outstanding, progress percentage, task list, search box |
| Task manager | Create and manage tasks | Title, due date, add button, edit / complete / delete per task |
| Support booking | Ask for help | Topic, preferred date, notes, submit button, booking list |
| Resources | Learning material | [List your resource page contents] |
| Mini-game | Practise coding | Question, answer buttons, score |
| Settings | Preferences | Light/dark theme choice |
| Assessor view | Review bookings | Learner, topic, date, status selector |

## Design decisions
- One navigation bar on every screen so learners always know where they are.
- Errors appear next to the form that caused them, in plain language.
- Overdue tasks are marked so learners notice them.
- Light and dark theme, saved as a cookie preference.
- The print layout shows only the dashboard summary.
