# Client Brief: SkillsTrack Learner Support Portal

## Client
SkillsTrack Training Centre

## Background
Learners currently record goals, tasks, support bookings and progress in separate documents and messages. Assessors cannot easily see outstanding work or which learners need support.

## Problem
There is no single place where a learner can manage their work and ask for help, and no single place where an assessor can see who needs support.

## What the client wants
A browser-based portal built with HTML5, CSS3 and JavaScript (ES6+), using Firebase for storage and sign-in, where:
- Learners register, sign in and see only their own information.
- Learners create, edit, complete and delete learning tasks.
- Learners see a dashboard with totals and a progress percentage.
- Learners book support sessions.
- Learners search and filter their tasks.
- Learners play a short coding mini-game that saves its score.
- Learners print a progress summary.
- Assessors view support bookings and update their status.

## Users
| User | Needs |
|---|---|
| Learner | Manage tasks, book support, see progress, play the mini-game |
| Assessor / Administrator | See bookings, identify learners who need help, update booking status |

## Constraints
- HTML5, CSS3, JavaScript (ES6+) only
- Firebase Authentication and Firebase database via REST API
- No unrestricted public read/write database rules
- No passwords or secrets in cookies, source code or GitHub
- Team of three using Git branches, pull requests and peer review
- Two milestones: Month 1 (planning and app shell) and Month 2 (final integration)

## Success criteria
- A learner can register, log in, manage tasks and book support without help.
- The dashboard progress figure is correct after every change.
- An assessor can see and update bookings.
- The code and history are available on GitHub.
